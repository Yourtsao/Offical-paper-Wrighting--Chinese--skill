# 国企公文写作 AI 技能包 📝

**38 类文种 · 76 篇精选范例 · 喂给你的 AI，秒变笔杆子**

> 体制内写材料的人都知道：公文写作的门道，不在"会写字"，在"懂门道"。
> 这个技能包把请示、报告、总结、讲话稿、纪要、函、党课、金句等 38 类文种的方法论和范例整理成 AI 可直接使用的技能文件——你只要说"写一份请示"，AI 就知道按什么结构、什么语气、什么规范来写。

---

## 为什么值得用

| 痛点 | 这个包怎么解决 |
|------|--------------|
| AI 写公文像大白话 | 76 篇精选范例喂进去，AI 自动学语气、学结构 |
| 不知道每种文种怎么写 | 38 类全覆盖，每类 2 篇代表作，讲透结构和写法 |
| 格式老被领导挑 | 内置公文写作铁律：标题不加粗、仿宋正文、数字 Times New Roman |
| 网上资料又杂又重复 | 每类只留 2 篇精华，去重精选，不浪费 token |

## 快速上手

**方式一：Hermes Agent（推荐）**

```bash
# 将技能包放入技能目录
# ~/.hermes/skills/ 或 AppData/Local/hermes/skills/
# 然后对你的 AI 说："帮我写一份向集团申请增加预算的请示"
```

**方式二：任意 AI（Claude / GPT / 文心 / 豆包）**

把 `references/请示/` 下的 2 篇范例 + 你的需求一起粘贴给 AI，说"按这个风格和结构写"。

## 内容说明

- 全部内容为通用公文写作方法论与范例，**已完全脱敏**，不含任何单位、个人真实信息，可放心用于商业交付和二次创作
- 每类精选 2 篇代表作的逻辑：结构最典型 + 写法最讲究，避免同类资料堆积
- 内置写作铁律：文种用语精确（议案用"推荐/免去"、决议用"同意/选举/免去"）、层级标题不加粗、黑体标题首行缩进、段落间不空行
